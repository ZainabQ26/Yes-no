# Yes/No Project

Small project for user to pick yes or no ultimately deleting anyways.

## Technologies

- **Language:** JavaScript 
- **Framework:** React 
- **Package manager:** npm

## Features

- Two-screen flow: `prompt` and `game` modes
- Position-based animation driven by `useEffect` and inline styles
