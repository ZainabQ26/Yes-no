# Yes/No Project

Fun program doesn't take no for an answer

## Technologies
- JavaScript
- React
- npm

## Run
```bash
cd clippy-trap
npm install
npm start
```

Open `http://localhost:3002` in your browser.

## Features
- Simple yes/no interaction
- Two-screen flow
